# Praćenje Kućnog Budžeta (C++ / Qt)

Desktop aplikacija dizajnirana za praćenje ličnih troškova, prihoda i vizuelnu analitiku budžeta koristeći C++, Qt Framework i SQLite.

## Funkcionalnosti
- **Upravljanje transakcijama:** Dodavanje, izmjena i kategorizacija svakodnevnih troškova i prihoda.
- **Integracija baze podataka:** Trajno pohranjivanje podataka omogućeno putem SQLite-a.
- **Interaktivni UI:** Korisnički interfejs jednostavan za korištenje, dizajniran pomoću Qt Designer-a.

## Tehnologije (Tech Stack)
- **Jezik:** C++
- **Framework:** Qt 5 / Qt 6
- **Baza podataka:** SQLite
- **Alati:** Qt Creator, HeidiSQL / DB Browser for SQLite

## Kako pokrenuti projekat
1. Klonirajte repozitorijum: `git clone https://github.com/anesssEV9/kucni-budzet-qt.git`
2. Otvorite `untitled.pro` u Qt Creator-u.
3. Pokrenite projekat (Ctrl + R).
